# VectorColumn

A vector drawn with **real square brackets** (tick – vertical – tick SVG paths), values bold, one per
row; `highlight` turns one row red. Never draw a vector or matrix as a plain rectangle.

```jsx
<VectorColumn x={1480} y={840} values={['0.2', '-0.1', '0.4']} label="Vector minh họa" />
```

Use to show token → embedding, or the numbers entering a layer; animate values with count-ups.
